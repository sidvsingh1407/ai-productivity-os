# AI Productivity OS

## Project Overview
AI Productivity OS is a comprehensive platform consisting of a Python/FastAPI backend and a React/Vite frontend. It provides robust capabilities for managing workflows, running audits, and scaling organizational productivity.

## Setup Instructions

### Prerequisites
- Python 3.11+
- Node.js 18+ (with npm)
- Docker & Docker Compose (optional but recommended for Redis)
- PostgreSQL (Supabase or equivalent)

### Environment Variables
Configure the following environment variables. Use the `.env.example` file in the `backend/` directory as a reference.

**Backend (`backend/.env`):**
- `DATABASE_URL`: PostgreSQL connection string using the `postgresql+asyncpg://` scheme.
- `REDIS_URL`: Redis connection string (e.g., `redis://localhost:6379`).
- `SECRET_KEY`: Secret key for JWT encoding/decoding.
- `FRONTEND_URL`: The URL where the frontend is running (e.g., `http://localhost:5173`).

### Local Development

#### Running the Backend
Navigate to the `backend/` directory, install requirements, and run the server:
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

#### Running the Frontend
Navigate to the `frontend/` directory, install dependencies, and start the development server:
```bash
cd frontend
npm install
npm run dev
```

#### Running the Celery Worker
Navigate to the `backend/` directory and run the Celery worker for background tasks:
```bash
cd backend
celery -A tasks.celery_app worker --loglevel=info
```

#### Running Database Migrations
Make sure `DATABASE_URL` is configured and run:
```bash
cd backend
alembic upgrade head
```

## API Documentation
The API documentation is auto-generated by FastAPI. When the backend is running, access it at:
[http://localhost:8000/api/docs](http://localhost:8000/api/docs)

## Deployment Instructions

### Deploying the Backend (Railway)
The backend is configured for deployment on Railway using the root `railway.json`.
1. Connect your GitHub repository to Railway.
2. Railway will automatically use `railway.json` from the repository root to install dependencies and start the app using `uvicorn`.

### Deploying the Frontend (Vercel)
The frontend is configured for deployment on Vercel using `frontend/vercel.json`.
1. Connect your GitHub repository to Vercel.
2. Ensure Vercel is set to build the `frontend` directory. Vercel will automatically use `vercel.json` for build settings, output directory (`dist`), and routing configuration (rewriting all traffic to `/index.html`).
